## 5. What CoCo got wrong

1. **It mislabelled a gate for three sessions.** `STATE.md` called the agent work "`G3` — answers are
   trustworthy" and marked it passed; the plan's `G3` is the numbers, which did not exist. The audit this
   session caught it by reading the gate table rather than the status file. The assertions were relabelled.
2. **It nearly built a fake Performance factor.** The generator's power was `ideal × 0.965` everywhere, so a
   straightforward build would have produced ~96.5% on every turbine and passed `T-25` on measurement noise —
   the exact defect `ADR-0003` was written against. Caught by reading the generator before writing the view;
   logged as `I-20`.
3. **Four Snowflake Scripting mistakes** in the numbers procedure, each caught at compile or first run:
   `SELECT … INTO` after a `WITH`, a scalar subquery in an `INTO` list, a missing column alias on the first
   `UNION` branch, and a boolean concatenated into text.
4. **`T-33` for the scheduler first "failed" for the wrong reason**: `WOA_SCHEDULER` is correctly denied the
   app warehouse, so the test never reached its `INSERT`. The strict error-code match refused to count that as
   a pass; the role now runs on its own warehouse.
5. **A temp table without a schema** failed under `snow sql --stdin`, which has no current schema.
